# Release Notes v1.0.0

## 🇳🇱 Dutch Localization

The entire application has been fully translated to Dutch!

- **User Interface**: All pages, forms, buttons, and messages are now in Dutch.
- **Database**: The default seed data for exercises and food items is now in Dutch.
- **Metadata**: App title and description are localized.

## 🚀 Features

- **Authentication**: Secure Sign In and Sign Up flows.
- **Workouts**: Log workouts, view history, and manage exercises.
- **Nutrition**: Track daily food intake and macronutrients.
- **Progress**: Visualize weight and training volume trends.
- **Goals**: Set and track fitness goals.
- **Measurements**: Log body measurements over time.
- **PWA**: Installable on mobile devices.

## 📦 Deployment

- **Docker**: Ready for containerized deployment.
- **Version**: 1.0.0
